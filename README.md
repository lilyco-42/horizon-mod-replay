# horizon-mod-replay (`replay_recorder` v2.0.0)

Standalone **Horizon** native mod for in-game replay recording and keyframe bookmarking (`R` toggle / `B` bookmark).

## Build & Install
```bash
horizon-launcher native-build \
  --version nightly-2026-11-20-0a875da \
  --trust-native-code .
```

Part of the [lilyco-horizon](https://github.com/lilyco-42/lilyco-horizon) ecosystem.
